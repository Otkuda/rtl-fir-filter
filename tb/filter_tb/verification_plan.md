### План тестирования КИХ-фильтра

| Название и описание | Ожидаемый результат |
| :--- | :--- |
| **1. Проверка импульсной характеристики**<br>*Проверяет:* Правильность загрузки коэффициентов и базовую работу вычислительного блока. | На выходе должна появиться точная копия загруженных коэффициентов. |
| **2. Проверка переходной характеристики**<br>*Проверяет:* Правильность загрузки коэффициентов, работу вычислительного блока и линии задержки. | На выходе должна появиться нарастающая сумма коэффициентов. |
| **3. Проверка нормальной фильтрации**<br>*Проверяет:* Математическую корректность работы всего модуля. | Отфильтрованный сигнал полностью совпадает с математическим эталоном. |
| **4. Проверка насыщения**<br>*Проверяет:* Корректную работу при превышении максимального значения. | Выход фиксируется на максимальном по модулю значении (не происходит переполнения через ноль). |
| **5. Backpressure**<br>*Проверяет:* Логику управляющего автомата при остановке принимающего устройства. | Управляющий автомат останавливается до появления «1» на `m_axis_tready`. Входной сигнал не теряется, искажений данных нет. |
| **6. Отсутствие входа**<br>*Проверяет:* Логику управляющего автомата при отсутствии новых входных данных. | Управляющий автомат останавливается до появления «1» на `s_axis_tvalid`. Выходные данные формируются реже, но их значения совпадают с эталонными. |
| **7. Переконфигурация фильтра**<br>*Проверяет:* Корректность работы модуля при смене коэффициентов ИХ после сброса. | Фильтр корректно применяет новые коэффициенты. Переходные процессы (если не предусмотрен сброс линии задержки) или новые данные соответствуют обновленной ИХ. |
| **8. Тесты со скважностью**<br>*Проверяет:* Работу конвейера при разном темпе поступления данных.<br> |  |
|**8.1 Скважность равна длине ИХ**|Данные не теряются. Результат совпадает с эталоном|
|**8.2 Скважность больше длины ИХ**|Данные не теряются. Результат совпадает с эталоном|
|**8.3 Скважность меньше длины ИХ**||
|**8.3.1 С проверкой tready**|Данные не теряются. Результат совпадает с эталоном, входной поток данных останавливается до готовности входного FIFO|
|**8.3.2 Без проверки tready ИХ**|Данные теряются, входной поток данных игнорирует `tready`|
| **9. Тесты на разных значениях параметра DEPTH**<br>*Проверяет:* Масштабируемость (параметризуемость) модуля на уровне кода.<br> | Дизайн успешно собирается/симулируется при любой заявленной глубине. Количество обрабатываемых коэффициентов и задержка строго соответствуют параметру. |
| **10. Загружаемая ИХ больше чем максимально возможная**<br>Проверяет: Защиту от некорректной конфигурации или переполнения памяти коэффициентов. | Фильтр обрезает ИХ до максимально возможной длины, игнорируя лишнее |
