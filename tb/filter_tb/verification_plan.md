### План тестирования КИХ-фильтра

1. **Проверка импульсной характеристики** 

  - Проверяет:
    - Правильность загрузки коэффициентов
    - Базовую работу вычислительного блока

  - Входное воздействие:
    - Единичный импульс

  - Ожидаемый результат:
    - На выходе должна появиться точная копия загруженных коэффициентов


2. **Проверка переходной характеристики** 

  - Проверяет:
    - Правильность загрузки коэффициентов
    - Базовую работу вычислительного блока
    - Корректность работы линии задержки

  - Входное воздействие:
    - Единичный скачок

  - Ожидаемый результат:
    - На выходе должна появиться нарастающая сумма коэффициентов 


3. **Проверка нормальной фильтрации**

  - Проверяет:
    - Математическую корректность работы всего модуля

  - Входное воздействие:
    - Комплексный сигнал

  - Ожидаемый результат:
    - Отфильтрованный сигнал, совпадающий с эталоном


4. **Проверка насыщения**

  - Проверяет:
    - Корректную работу при превышении макисмального значения

  - Входное воздействие:
    - Сигнал с максимальной амплитудой

  - Ожидаемый результат:
    - Выход фиксируется на максимальном по модулю значению

4. **Backpressure**

  - Проверяет:
    - Логику работы управляющего автомата при остановке принимающего устройства

  - Входное воздействие:
    - Сигнал `m_axis_tready` периодически опускается в 0 на случайное число тактов

  - Ожидаемый результат:
    - Управляющий автомат останавливается до появления 1 на сигнале `m_axis_tready`, входной сигнал не теряется

5. **Отсутсвие входа**

  - Проверяет:
    - Логику работы управляющего автомата при отсутствии новых входных данных

  - Входное воздействие:
    - Сигнал `s_axis_tvalid` периодически опускается в 0 на случайное число тактов

  - Ожидаемый результат:
    - Управляющий автомат останавливается до появления 1 на сигнале `s_axis_tvalid`, выходные данные формируются реже, но совпадают с эталонными
